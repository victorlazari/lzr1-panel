lzr1 panel: right-click menus

Five styles for the menu a right-click opens (or a left-click, with LZR1_MENU_BUTTON=left; m opens it from the keyboard). Each style shows the menu of a session on the left and of a pull request on the right, as fzf draws it in the 56-column panel. Style 1, plain list, is the one lzr1-panel uses (chosen on 28 Oct 2026). Hover a line to move the pointer. The rows are sample values: “another example” redraws every menu with other sessions and PRs, so you can see how each style copes with long names, waiting sessions, failing checks and drafts.
