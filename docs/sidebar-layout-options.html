how it works in bin/lzr1-panel

            
Zero-Dependency Zsh + fzf Implementation

            

              1. Profile Order & Gap: Saved in ~/.config/lzr1-panel/layout.conf (order=lerian,lzr1-macbook-air, profile_gap=2). Clicking a profile header or using [≡ menu] → Organize Profiles moves it up/down or adjusts spacing.

              2. PR Section Position & Height: Controlled by pr_gap (blank rows pushing PRs down) and pr_height (max visible PRs before scrolling).

              3. Per-Section Scrollbar: When PRs or sessions exceed their viewport window, right-column cells render █ (thumb) and ░ (track) with ▲ scroll up / ▼ scroll down rows.
