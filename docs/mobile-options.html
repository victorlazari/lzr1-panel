lzr1-panel on a phone: five options

The remote panel already opens in a phone browser over Tailscale. These five options show how it could look and work there, from what is built today to an inbox that answers a waiting session in one tap. Every phone runs the same sample sessions, so only the layout changes.

What the phone has to show

The panel lists Claude Code and opencode sessions running in tmux on several machines (profiles), with open pull requests below. Each phone needs the same pieces.

Sample data SAMPLE

All sessions, branches, machines, PRs and ages in the phones are made-up samples: sessions billing-portal, atlas, garden; machines oracle-sessions, macbook-pro-sessions. Session output is drawn as grey bars, and the answer choices are sample wording.

Facts every option must respect

  • Each session row has 3 lines: state, name, model and age; what it is doing or the question it waits on; branch with changed-file count, and folder.
  • Footer buttons: [+opus] [+sonnet] [+opencode] [web] [↻] [?].
  • The phone browser shows a terminal (xterm.js via ttyd), about 46 columns wide.
  • Under 86 columns the panel shows the list or a session, one at a time.
