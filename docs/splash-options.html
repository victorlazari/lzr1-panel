lzr1 splash: pick one

Ten candidates for the animation lzr1-panel plays on install and every time it opens: about 5 seconds, any key skips it. All ten use the same logo, status messages and loading bar, so only the motion differs. The counts in the messages are sample values; in the terminal they come from your real profiles. Option 10, BIOS boot, is the one lzr1-panel plays (chosen on 27 Oct 2026); the others stay here for reference.

Colors here use the Lerian palette. In the terminal, the logo uses a cyan-to-magenta 256-color gradient, and every option fits any window size, falling back to a one-line logo in small terminals.
